Getting started

Use this order when setting up a new local installation.

  • Sign in with your local administrator account.
  • Authorize each data provider separately from the project terminal.
  • Select TradingView or Webull in the Overview provider control.
  • Choose an instrument and timeframe in Charts.
  • Review data source, delay and cache status before relying on a value.

Market-data connections

TradingView: separate OAuth authorization; read-only history.

Webull: separate Cloud MCP OAuth; market:read and instrument:read only.

Yahoo Finance: news and calendar context, not a guaranteed real-time futures feed.

GEX: on-demand options-derived estimates with source and timing limitations.

Local terminal commands

Run from the Futures Mission Control project directory with the virtual environment.

  • python -m mission_control.webull_auth ? Webull authorization.
  • python -m mission_control.tradingview_auth ? TradingView authorization.
  • python -m pytest -q ? project regression tests.
  • python -m mission_control.main ? use the project's documented server command if available.

Security & trading safeguards

  • Local administrator login protects dashboard and API routes.
  • Provider credentials are not stored in dashboard HTML.
  • Webull adapter exposes an explicit read-only tool allowlist.
  • TradingView remains read-only.
  • Master Risk Engine and human approval remain separate from data providers.
  • Order execution remains disabled.
